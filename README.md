A Smart Student Performance Analysis System I developed using Python.
It takes student details and marks in multiple subjects, calculates total marks, averages, percentages and grades, and ranks students based on their performance. 
It also identifies students who are at risk of failing, performs subject-wise analysis, calculates class statistics, and generates performance reports. 
I used OOP concepts, classes, dictionaries, lists, sorting, exception handling and CSV file handling to build it.
